# Parties 🎀

Invite pages for family parties, hosted on GitHub Pages. Each party gets its own folder.

| Party | Folder | Link |
| - | - | - |
| Nora turns 9 (Nov 15, 2026) | `nora-9/` | https://katekness.github.io/parties/nora-9/ |

## Privacy
- Every page has `noindex, nofollow` tags and the repo has a `robots.txt`, so search engines are told to skip it.
- No home address on any page. Guests RSVP and get the address by text.
- Note: the repo itself is public unless you make it private (private repos need a paid GitHub plan for Pages).

## Making a new party
1. Copy a party folder, e.g. `nora-9/` to `ellie-7/`.
2. In the new `index.html`, edit the `EDIT THESE` block near the bottom (date, title, wishlist, registry link) and the text in the hero card.
3. Make a new RSVP form in Tally (duplicate the old one) and swap the form ID in the RSVP iframe.
4. Commit. The page goes live at `https://katekness.github.io/parties/<folder>/`.
